Key Formulas · Probability
Complement: \(P(A') = 1 - P(A)\)
Union (2 events): \(P(A\cup B)=P(A)+P(B)-P(A\cap B)\)
Union (3 events): \(P(A\cup B\cup C)=P(A)+P(B)+P(C)-P(A\cap B)-P(A\cap C)-P(B\cap C)+P(A\cap B\cap C)\)
Conditional: \(P(A|B)=P(A\cap B)/P(B)\)
Independent: \(P(A\cap B)=P(A)\cdot P(B)\)
Bayes: \(P(A_i|D)=\dfrac{P(A_i)P(D|A_i)}{\sum_j P(A_j)P(D|A_j)}\)
Series reliability: \(R=R_1\times R_2\times\cdots\times R_n\)
Parallel reliability: \(R=1-(1-R_1)(1-R_2)\cdots(1-R_n)\)
Binomial: \(P(X=x)=\binom{n}{x}p^x q^{n-x},\quad \mu=np,\quad \sigma^2=npq\)
Poisson: \(P(X=x)=\dfrac{e^{-\lambda}\lambda^x}{x!},\quad \mu=\sigma^2=\lambda\)   (Poisson approx: \(\lambda=np\), \(n\) large, \(p\) small)
Geometric: \(P(X=x)=q^{x-1}p,\quad P(\text{no success in } k) = q^k\)
Standard normal: \(Z=(X-\mu)/\sigma\);   \(\Phi(-z)=1-\Phi(z)\)
Percentile: \(x=\mu+z\sigma\)
Empirical rule: \(\mu\pm\sigma\): 68.27%; \(\mu\pm2\sigma\): 95.45%; \(\mu\pm3\sigma\): 99.73%

Group 1  ·  Probability Rules, System Reliability and Bayes’ Theorem  (E3.1·E3.8)

E3.1 Series circuit · three components

A series circuit has three independent components with reliabilities \(R_1=0.95\), \(R_2=0.90\), \(R_3=0.85\). Find the reliability of the circuit.

Solution

In a series system, the system works only if all components work:

\[R_\text{system} = R_1 \times R_2 \times R_3 = 0.95\times0.90\times0.85 = 0.7268\]

System reliability = 0.7268 (72.68%)
E3.2 Parallel circuit · two components

A parallel circuit has two independent components with reliabilities \(R_1=0.90\) and \(R_2=0.85\). Find the reliability of the system.

Solution

In a parallel system, the system fails only if all components fail. Failure probabilities: \(F_1=0.10\), \(F_2=0.15\).

\[R_\text{system} = 1 - F_1\times F_2 = 1-0.10\times0.15 = 0.985\]

System reliability = 0.985 (98.5%)
E3.3 Series–parallel combined circuit

A circuit has two subsystems in series. Subsystem A has two components in parallel with reliabilities 0.90 and 0.85. Subsystem B has two components in parallel with reliabilities 0.95 and 0.80. Find the overall reliability.

Solution

\(R_A = 1-(1-0.90)(1-0.85) = 1-0.015 = 0.985\)

\(R_B = 1-(1-0.95)(1-0.80) = 1-0.010 = 0.990\)

\(R_\text{system} = R_A\times R_B = 0.985\times0.990 = 0.9752\)

System reliability = 0.9752 (97.52%)
E3.4 Reliability · four components in parallel

Four independent components, each with reliability 0.75, are connected in parallel. Find the system reliability.

Solution

Each component fails with probability 0.25. The system fails only if all four fail:

\[R = 1-(0.25)^4 = 1-0.003906 = 0.9961\]

System reliability = 0.9961 (99.61%)
E3.5 Series circuit · four components

Four independent components with reliabilities 0.99, 0.95, 0.90, and 0.85 are connected in series. Find the system reliability.

Solution

\[R = 0.99\times0.95\times0.90\times0.85 = 0.7198\]

System reliability = 0.7198 (71.98%)
E3.6 Mixed series–parallel network

Component A is in series with a parallel block containing components B and C. Reliabilities: \(R_A=0.98\), \(R_B=0.92\), \(R_C=0.88\). Find the system reliability.

Solution

Parallel block (B and C): \(R_{BC}=1-(1-0.92)(1-0.88)=1-0.08\times0.12=0.9904\)

Overall (A in series with BC): \(R=0.98\times0.9904=0.9706\)

System reliability = 0.9706 (97.06%)

E3.8 Bayes’ theorem · washer factory quality control

Three procedures A, B, C produce 25%, 35%, and 40% of the washers in a factory, with defect rates of 0.5%, 0.4%, and 0.2% respectively. A randomly selected washer is found to be defective. Find the probability it came from each procedure.

Solution

\(P(D)=0.25(0.005)+0.35(0.004)+0.40(0.002)=0.00125+0.00140+0.00080=0.00345\)

\(P(A|D)=\dfrac{0.25\times0.005}{0.00345}=\dfrac{0.00125}{0.00345}=0.3623\)

\(P(B|D)=\dfrac{0.35\times0.004}{0.00345}=\dfrac{0.00140}{0.00345}=0.4058\)

\(P(C|D)=\dfrac{0.40\times0.002}{0.00345}=\dfrac{0.00080}{0.00345}=0.2319\)

P(A|D) = 36.23%, P(B|D) = 40.58%, P(C|D) = 23.19%. Procedure B is most likely responsible.

Group 2  ·  Discrete Probability Distributions: Binomial, Poisson, Geometric  (E3.9·E3.20)

E3.9 Practical uses of discrete probability distributions

Explain the practical uses of discrete probability distributions in engineering and technology.

Solution

Binomial distribution \(B(n,p)\): used when there are \(n\) independent trials, each with two outcomes, and constant probability \(p\). Engineering uses: number of defective items in a batch, number of error bits in a data packet, number of machines failing in a day.

Poisson distribution \(\text{Po}(\lambda)\): models the number of rare events occurring randomly in a fixed interval of time, length, or area. Examples: network packet arrivals per second, defects per metre of wire, accidents per month on a highway, HTTP requests to a server per minute.

Geometric distribution: number of trials until the first success. Examples: number of bits transmitted until the first error, number of parts tested until the first defective is found, number of oil wells drilled until the first strike.

E3.10 When the binomial distribution approximates the Poisson

State the conditions under which the Poisson distribution is used as an approximation to the binomial distribution.

Solution

The Poisson distribution approximates \(\text{Binomial}(n,p)\) when:

1. The number of trials \(n\) is large (conventionally \(n\ge30\) or \(n\ge50\)).

2. The probability of success \(p\) is small (conventionally \(p\le0.05\)).

3. The mean \(\lambda=np\) is moderate (typically \(\lambda\le5\)).

Under these conditions, \(\text{Binomial}(n,p)\approx\text{Poisson}(\lambda=np)\), which is easier to compute because it has only one parameter. The approximation improves as \(n\to\infty\) and \(p\to0\) with \(np\) held constant.

E3.11 Binomial · error detection in a data packet

A data packet contains 20 bits. Each bit is independently corrupted with probability 0.05. Find the probability that: (a) exactly 2 bits are corrupted, (b) at most 1 bit is corrupted.

Solution

\(X\sim B(20,\;0.05)\), \(q=0.95\).

(a) \(P(X=2)=\binom{20}{2}(0.05)^2(0.95)^{18}=190\times0.0025\times0.3972=0.1887\)

(b) \(P(X=0)=(0.95)^{20}=0.3585\); \(P(X=1)=20(0.05)(0.95)^{19}=0.3774\)

\(P(X\le1)=0.3585+0.3774=0.7359\)

(a) 0.1887   (b) 0.7359
E3.12 Binomial · airline no shows

An airline knows 8% of passengers with a ticket do not show up. The airline sells 10 tickets for a plane with 9 seats. Find: (a) P(all 10 show up), (b) P(exactly 9 show up), (c) P(fewer than 9 show up).

Solution

\(X\sim B(10,\;0.92)\) (number who show up), \(q=0.08\).

(a) \(P(X=10)=(0.92)^{10}=0.4344\)

(b) \(P(X=9)=10(0.92)^9(0.08)=10\times0.4722\times0.08=0.3777\)

(c) \(P(X\le8)=1-P(9)-P(10)=1-0.3777-0.4344=0.1879\)

(a) 0.4344   (b) 0.3777   (c) 0.1879

E3.16 Poisson approximation to binomial · bit errors

A data stream of 1000 bits is transmitted. Each bit is independently in error with probability 0.001. Use an appropriate approximation to find P(at least 2 bits are in error).

Solution

Since \(n=1000\) (large) and \(p=0.001\) (small), use the Poisson approximation with \(\lambda=np=1\).

\(P(X=0)=e^{-1}=0.3679,\quad P(X=1)=e^{-1}=0.3679\)

\(P(X\ge2)=1-0.3679-0.3679=0.2642\)

Cracks occur in a highway at a rate of 3 per mile (Poisson). Find: (a) P(no crack) in a 5-mile stretch, (b) P(at least 1 crack) in a 0.5-mile stretch, (c) P(at most 2 cracks) in a 1-mile stretch.

E3.21 Normal distribution · area properties and the empirical rule

State the area properties of the normal distribution and the empirical rule.

Solution

The standard normal curve \(Z\sim N(0,1)\) is symmetric about zero, bell shaped, and the total area under the curve equals 1.

Empirical rule for \(X\sim N(\mu,\sigma^2)\):

\[P(\mu-\sigma < X < \mu+\sigma) = 68.27\%\]

\[P(\mu-2\sigma < X < \mu+2\sigma) = 95.45\%\]

\[P(\mu-3\sigma < X < \mu+3\sigma) = 99.73\%\]

These follow from the standard normal table: \(\Phi(1)-\Phi(-1)=0.6827\), \(\Phi(2)-\Phi(-2)=0.9545\), \(\Phi(3)-\Phi(-3)=0.9973\).

E3.30 Normal distribution · satellite missile targeting

A satellite missile manufacturer claims his newly produced missile will strike within 10 feet of the target (defined as a “success”). Previous records show the mean targeting offset from the target is 1.5 feet with a standard deviation of 10 feet, and the striking range follows approximately a Gaussian distribution.

(i) Find the probability that the missile will fail the target. (ii) Find the chance of hitting the target (within the 10-foot range). (iii) Find the range of target area for which there is a 90% chance on the lower side of the normal curve.

Solution

Let \(X\sim N(\mu=1.5,\;\sigma^2=10^2)\) be the signed offset from the target. “Success” means \(-10\le X\le 10\).

(i) P(fail) = P(X < −10) + P(X > 10)

\[z_1=\frac{-10-1.5}{10}=-1.15,\qquad z_2=\frac{10-1.5}{10}=0.85\]

\[P(X\lt-10)=\Phi(-1.15)=1-\Phi(1.15)=1-0.8749=0.1251\]

\[P(X\gt10)=1-\Phi(0.85)=1-0.8023=0.1977\]

\[P(\text{fail})=0.1251+0.1977=\mathbf{0.3228}\]

(ii) P(hit within 10 feet) = 1 − P(fail)

\[P(\text{success})=1-0.3228=\mathbf{0.6772}\]

So there is roughly a 67.72% chance of a successful strike.

(iii) 90th percentile on the lower side: Find \(x\) such that \(P(X\le x)=0.90\).

\[z_{0.90}=1.2816\]

\[x=\mu+z\sigma=1.5+1.2816\times10=1.5+12.82=\mathbf{14.32}\text{ feet}\]

There is a 90% chance that the missile strikes within 14.32 feet of the aim point on the lower side of the curve.

P(fail) = 32.28%  |  P(success within 10 ft) = 67.72%  |  90% lower-side range = 14.32 ft
